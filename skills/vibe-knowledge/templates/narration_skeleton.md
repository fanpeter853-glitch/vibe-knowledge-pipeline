# 旁白骨架（自己写的，6 种母版）

> 来源思路：andyhuo520/vibe-knowledge 的 6 种母版（概念），
> 这里的文字是我方按 Peter 的小号重写的短版骨架，不是原仓库的骨架文件。
> 完整骨架在 `templates/narration/A–F.json`（已改编：配音引擎改成 Peter 自己录）。
> 60–90 秒约 330–500 字，先猜后讲、标题延后、一个主道具贯穿、结尾回问。

## A · 猜谜概念片（小号首选）

适合：一个抽象概念。拍：冷开场先猜 → 点题 → 小游戏量化 → 谁、哪年命名（须有出处）
→ 本土例子 → 公式只出现一次 + 一句大白话 → 亲身体验 → 金句 → 尺度拉大 → 反转 → 边界 → 落回观众 → 首尾回环。

## B · 两难选择片

适合：历史事件、博弈、心理实验。拍：离奇事实 → 换你选 → 系列片头 → 前情 →
经过（数字一步步滚上去，分歧两说并列）→ 等待 → 揭晓 → 金句。

## C · 痛点原理片（小号首选）

适合：提效工具、方法类。拍：先讲一个疼的问题 → 问题到底多疼（一个数 + 出处）→
原理拆开 → 方法三步 → 容易踩的坑 → 金句 → 回问观众卡在哪一步。

## D · 一条主线片

适合：一个主角 / 一条线讲到底。拍：主角出场 → 遇到问题 → 试了什么 → 转折 →
结果 → 这条线说明了什么。

## E · 闯关片

适合：步骤多的流程。拍：第一关 → 第二关 → 第三关 → 每一关一个坑 → 通关 → 回顾。

## F · 六面轮转片

适合：一个概念六个面。拍：六个面轮着讲，每面一句话 + 一个画面，45–60 秒。
