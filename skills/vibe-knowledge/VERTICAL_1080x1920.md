# 竖屏预设：1080×1920，中文，自己配音

来源改编：andyhuo520/vibe-knowledge，原默认 16:9 1080p60。
本预设是 Peter 小号 vibe 第一期的默认，横屏只当备选。

## 画幅与时长

- 画幅：1080×1920，竖屏 9:16。
- 时长：第一期先按 60 秒左右，约 250–330 字起步；跑通后再决定是否拉长到 2 分钟 / 400–500 字。
- 帧率：目标 60fps 代码渲染（待验证，本机渲染未跑通前不要承诺）。
- 画面字：每屏只放关键词，≤8 字一组，同屏最多两组；整句交给旁白和字幕。
- 静止画面：最长静止 ≤3 秒，每章一个“王炸”镜头（代码粒子、视差、计数器、地图扩散等，不用付费动态镜头）。

## 声音

- 旁白：Peter 自己录，优先。分段录音单对齐旁白稿，时间线以真实录音时长为准。
- 不用 MiMo，不用仓库默认 AI 音色，不存任何配音 API key。
- BGM：不强制用原仓库默认 BGM。由 Peter 在剪映里自己定，可无 BGM；如用 BGM，音量说话时比人声低 10 dB 左右。
- 音效：只用代码音效或剪映自带音效，不用付费音效库。

## 风格（先小范围）

- 先只考虑能讲干货、竖屏可读的风格，例如深色数学、暗金线描、星空光点、留白极简、瑞士网格动态字。
- 不选增强档风格：敦煌、青花、木刻、半调拼贴、长卷、铜版博物（都要生图）。
- 配色全片统一，深色底或浅色底二选一，不要一屏换一套。
- 人物用几何化无五官造型，不要写实人脸，不要用原仓库的 AI 示意人像当真人。

## 事实与出处

- 每期必建 `facts.md`，见本目录 `ADAPTED_SKILL.md` 里的规则。
- 每一个数字、人名、年份、引文都要有一行出处，分级 T1 / T2 / T3。
- 没有出处的不上屏；有分歧两说并列；示意画面标注“为示意”或角标“AI 示意图”。
- 不要编数字、不要用真实外贸成本做示例（瓷砖胶成本尚未确认，防水涂料 200 元/桶、20kg/桶不能混用）。

## 母版（小号先用两种）

- 首选 A 猜谜概念片，或 C 痛点原理片。
- 其他四种（B 两难选择片、D 一条主线片、E 闯关片、F 六面轮转片）以后再试。
- 结构：前 3 秒让观众参与（猜 / 选 / 认出日常场景），标题延后，
  一个主道具贯穿全片，每章一句金句收尾，结尾回扣开头、把问题交回观众。

## 分工（不要混用）

- vibe 代码动画：讲能画出来的知识点，不用真人出镜，不用 B-roll 连续性那套。
- Muse B-roll：讲个人经历 / 口播，单场景连续，尾帧当下一段首帧。
- 同一条视频只走一条路。
