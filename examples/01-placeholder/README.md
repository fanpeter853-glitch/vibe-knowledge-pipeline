## 画面 v3（2026-11-24，Peter 说 v2 还是太单调、改黑色系后重做）

- 构建脚本：`render/build_beats_v3.py` → `render/project_v3/b01.html…b06.html`，
  HyperFrames 本地渲染 → `render/out_v3/v3_*.mp4`，0.5 秒交叉淡化拼合。
- v2 抽帧诊断（逐秒抽帧看过 v2 带音乐版）：每拍同一版式（光点居中、
  关键词同一 y 值），舞台区只有一颗光点、中间大片空白，动画播一轮就停、
  后半段几乎不动，浅色底对比弱。
- v3 配色：深黑 / 炭黑底（`#0a0b10 → #12141f` 渐变，不纯黑死黑），
  加微弱金色/青色光晕；主色金色 `#f5c04e`、白色正文 `#f7f3e8`、
  青色点缀 `#63d8d2`、朱砂 `#e0705f` 少量。配色方向借鉴 Jensen
  《挚友往往相识于少年》黑底金字思路，画面、文案、图表全是本期自己的，
  不照搬那条。
- 三层同时动：底层 36 颗星点漂移闪烁 + 两团星云光晕呼吸 + 点阵底纹；
  中层主可视化连续生长（B01 光点沿曲线走、轨迹点依次亮、涟漪一圈接一圈；
  B02 六节点连线成网、双色线轮流脉动；B03 五重涟漪 + 双向轨道点；
  B04a 情绪/杏仁核/海马体三标签依次盖章 + 强度条注满回落；
  B04b 五块碎片拼合→散开→再拼合循环两轮；B04c 缺口圆环一直转 +
  双虚线弧画出收回；B05 双曲线边画边走、光点沿线走；B06 双投票条
  三轮起伏）；上层大字逐字出现、小字逐行淡入、学科标签 + 拍号 +
  底部进度条同步动。
- 版式每拍换一种排布：B01 居中、B02 左对齐、B03 居中、B04a 左对齐、
  B04b 居中、B04c 居中、B05 左对齐、B06 居中双栏；舞台占满竖屏。
- 转场：0.5 秒交叉淡化 + 主光点起止位置衔接（同一颗光点身份）。
  诚实说明：HyperFrames 是按拍分别渲染再拼合，不是同一块画布连续生长，
  拍与拍之间的“变形带到下一拍”只能靠光点衔接 + 淡化近似，做不到单画布
  像素级连续变形；淡化中间那 0.5 秒两拍文字会叠影，属正常转场。
- v3 渲染时发现并去掉的问题：初版有一条斜划金色细线（streak）在画面里
  像划痕，已从脚本里删掉再重渲。
